# Гранат Black — Меню

Android-приложение с меню ресторана [Гранат Black](https://granatblack.ru/menyu).

## Возможности

- 35 разделов меню, 300+ блюд
- Просмотр по категориям
- Корзина с подсчётом суммы
- Тёмная тема в стиле ресторана

## Сборка

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release-unsigned.apk`

## CI

GitHub Actions собирает APK при пуше в `main`.
